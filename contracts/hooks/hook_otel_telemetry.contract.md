# Contract: Hook — OTel Telemetry Collection

| Field | Value |
|-------|-------|
| contract_id | HC-OTEL-TELEMETRY |
| hook_name | OTel Telemetry Collection |
| event | pre_tool_use, post_tool_use, session_start, stop |
| version | 1.0.0 |

## Purpose

Collects OpenTelemetry metrics around each agent execution in the orchestrator pipeline. Tracks per-agent time, token usage, cost estimates, and produces a telemetry report for cost awareness and performance optimization.

## Key Outcomes

1. **[OUTCOME-BASELINE]** — On `SessionStart`, record global baseline metrics from Prometheus
2. **[OUTCOME-SNAPSHOT]** — On `PreToolUse` (subagent invocation), snapshot current metrics as agent start baseline
3. **[OUTCOME-DELTA]** — On `PostToolUse` (subagent completion), query metrics delta and compute per-agent cost
4. **[OUTCOME-REPORT]** — Append metrics to `telemetry_report.md` with per-agent breakdown
5. **[OUTCOME-COST]** — Estimate token costs using configurable model pricing table

## Trigger Conditions

| Event | Condition | Action |
|-------|-----------|--------|
| `SessionStart` | Pipeline begins | Record session-level baseline metrics |
| `PreToolUse` | `tool_name == "runSubagent"` | Snapshot pre-agent metrics |
| `PostToolUse` | `tool_name == "runSubagent"` | Query post-agent metrics, compute delta, append report |
| `Stop` | Pipeline ends | Finalize telemetry report, session cleanup |

## Metrics Collected

### Per-Agent Metrics

| Metric | Source | Description |
|--------|--------|-------------|
| `wall_time_seconds` | Hook timestamp diff | Wall-clock time for agent execution |
| `input_tokens` | Prometheus → OTel metrics | Tokens consumed in agent prompt |
| `output_tokens` | Prometheus → OTel metrics | Tokens generated by agent |
| `total_tokens` | Computed | `input_tokens + output_tokens` |
| `estimated_cost_usd` | Computed | `(input_tokens × input_rate + output_tokens × output_rate) / 1M` |
| `model` | Agent frontmatter / OTel labels | Model used for this agent |

### Session-Level Metrics

| Metric | Description |
|--------|-------------|
| `total_pipeline_time` | Total wall-clock time for all agents |
| `total_tokens_all_agents` | Sum of all agent tokens |
| `total_estimated_cost` | Sum of all agent costs |
| `agents_executed` | Count of agents that ran |

## Model Pricing Configuration

### Pricing Source Priority

1. **Environment variable** `OTEL_MODEL_PRICING_JSON` — inline JSON
2. **File** `OTEL_MODEL_PRICING_FILE` — path to pricing JSON file
3. **URL** `OTEL_MODEL_PRICING_URL` — remote pricing endpoint
4. **Defaults** — built-in model pricing table

### Pricing Format

```json
{
  "model-name": {
    "input": 5.00,
    "output": 25.00
  }
}
```

Values are **USD per 1 million tokens**.

### Default Pricing Table

| Model | Input ($/1M) | Output ($/1M) |
|-------|-------------|---------------|
| Configurable per customer | — | — |

The Pipeline Generator resolves model pricing at generation time based on the customer's approved models list from onboarding answers.

## Telemetry Report Format

The hook appends to `<output_folder>/telemetry_report.md`:

```markdown
## Agent: <agent_name>
| Metric | Value |
|--------|-------|
| Model | <model> |
| Wall Time | <seconds>s |
| Input Tokens | <count> |
| Output Tokens | <count> |
| Total Tokens | <count> |
| Est. Cost | $<amount> |
| Started | <timestamp> |
| Completed | <timestamp> |
```

### Session Summary (appended on Stop)

```markdown
## Pipeline Summary
| Metric | Value |
|--------|-------|
| Total Agents | <count> |
| Total Time | <seconds>s |
| Total Tokens | <count> |
| Total Cost | $<amount> |
```

## Workflow Logic

### PreToolUse (runSubagent)

1. Extract agent name from subagent prompt
2. Query Prometheus for current token counters: `copilot_tokens_total{service="<OTEL_SERVICE>"}`
3. Record snapshot: `{agent_name, start_time, baseline_tokens}`
4. Save snapshot to `observability/.hook-state/tooluse_<agent_id>.json`

### PostToolUse (runSubagent)

1. Load pre-snapshot from `observability/.hook-state/tooluse_<agent_id>.json`
2. Query Prometheus for current token counters
3. Compute deltas: `post_tokens - pre_tokens`
4. Compute wall time: `post_time - pre_time`
5. Look up model pricing → compute estimated cost
6. Append metrics to `telemetry_report.md`
7. Clean up snapshot file

### Prometheus Query

```promql
# Total tokens by model and direction
sum by (model, direction) (
  rate(copilot_tokens_total{service="OTEL_SERVICE"}[WINDOW])
)
```

## Exit Codes

| Code | Meaning | Agent Behavior |
|------|---------|----------------|
| `0` | Telemetry collected successfully | Pipeline proceeds |
| `1` | Telemetry degraded (Prometheus unreachable, metrics missing) | Pipeline proceeds, warning logged |

Telemetry collection MUST NEVER block the pipeline. All failures are non-blocking (exit 0 or 1, never 2).

## Customization Points

| Point | How Customized | Default |
|-------|---------------|---------|
| Prometheus URL | `PROMETHEUS_URL` env var | `http://localhost:9090` |
| OTel service name | `OTEL_SERVICE` env var | `copilot-chat` |
| Model pricing | Env var, file, or URL | Built-in defaults |
| Report path | Orchestrator output folder | `<output_folder>/telemetry_report.md` |
| Token metric name | OTel Collector config | `copilot_tokens_total` |

## Dependencies

- **HC-OBSERVABILITY** — OTel Collector and Prometheus must be running (started by the Observability hook)
- Prometheus must be scraping the OTel Collector's metrics endpoint
- OTel Collector must be receiving VS Code Copilot metrics via OTLP
